# CS530 Module 3: AI-Assisted Code Debugging and Evaluation

## Overview
This repository documents a comprehensive debugging exercise where GitHub Copilot was used to identify, analyze, and fix issues in a Python code snippet. The assignment reinforces the importance of effectively leveraging AI tools for code analysis and iterative refinement through structured dialogue.

## Project Contents

### 1. **Code Snippet** (`snippet.py`)
Contains a Python function `calculate_statistics()` that computes mean, minimum, and maximum values from a list of numbers. The function was intentionally designed to include several issues for debugging and evaluation purposes.

### 2. **Chat Log** (`chatlog.json`)
A complete transcript of interactions with GitHub Copilot documenting:
- **Well-structured prompts** constructed to evaluate and debug the code
- **Iterative prompt refinement** based on AI feedback to enhance the debugging process
- Complete dialogue demonstrating the feedback loop with the AI tool

### 3. **Debugging Report** (`CS530_Module3_Debugging_Report.docx`)
A 2-3 page formal report addressing all rubric criteria:

#### Part One: Prompt Engineering
- Demonstrates construction of well-structured prompts for code evaluation
- Shows iterative prompt revision based on AI feedback
- Documents the conversation flow and progression of debugging sessions

#### Part Two: Assessment and Efficiency Analysis
- **Assessment of AI Capability**: Evaluates how effectively the AI identified code issues
  - Includes specific reasoning for each identified issue
  - Provides concrete examples from the debugging session
  
- **Efficiency Evaluation**:
  - **Strengths**: Speed, comprehensiveness, ability to provide multiple perspectives
  - **Weaknesses**: Occasional over-explanation, formatting inconsistencies
  - **Reliability**: Consistency in identifying logical and structural issues

### 4. **Clear Communication**
The report maintains professional presentation with:
- Proper formatting (12-point Times New Roman, double spacing, 1-inch margins)
- Organized structure aligned with rubric criteria
- Clear examples and reasoning backed by actual AI interactions

## Key Findings

The debugging process revealed insights about:
1. How AI tools effectively identify logical and structural code issues
2. The importance of prompt clarity for obtaining actionable feedback
3. Iterative refinement techniques that improve AI-assisted debugging outcomes
4. Practical strengths and limitations of current AI tools in code analysis
